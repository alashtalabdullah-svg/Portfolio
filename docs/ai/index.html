03 — Agents

The system that runs without its author.

The fourth step of my method says: write the system so it runs without me. That used to mean a page someone else could read. Now it means something further — an agent that carries it out.

03.1 — The route

From a recurring task to a route that runs itself.

This is not "using AI tools". It is building a route with an input, an output and an owner — exactly like any operating procedure, except the thing executing it is a machine.

  1. 00

    A recurring task

    A weekly report, data entry, a follow-up, an internal message. Done by hand every time, at the same cost, with the same mistake.

  2. 01

    Design Claude Code

    I break the task into explicit written steps and state its inputs, its outputs and what counts as success. The route is written before it is run.

  3. 02

    Run Manus

    I connect the route and run it through an agent that carries it end to end, with no manual step left in the middle.

  4. 03

    Human review

    No output passes without a human eye. The agent executes; the decision stays with its owner — and this is not an extra step, it is the step that makes the rest trustworthy.

  5. 04

    Time recovered

    Turnaround shortens, manual load drops, and the team goes back to the work that genuinely needs a human head.

03.2 — Capabilities

Five capabilities, not five tools.

The tool changes every year. What lasts is knowing where to put it — and where it must not go.

A01

Agent deployment

Employing AI agents to execute and follow up on operational tasks — reports, correspondence, data entry and scheduling — under direct human supervision.

A02

Workflow design

Building workflow sequences with Claude Code, then connecting and running them through Manus to automate repetitive tasks end to end.

A03

Instruction design

Writing precise instructions and reusable templates that deliver consistent, verifiable outputs — not a fresh answer every time.

A04

Analysis & decision support

Using AI to analyse operational and financial data, surface trends, and prepare decision-ready summaries for management.

A05

Enablement & governance

Training the team on practical use, and setting the accuracy, quality and confidentiality guardrails for the tools — before they are opened up.

03.3 — The line

Where I stop automating.

  1. No decision without a person.The agent prepares, proposes and summarises. Approving something, sending it, spending against it — those steps carry a human name that signs for them.
  2. No system automated before it is understood.Automating a broken procedure gives you the same mistake a hundred times faster. Fix the system first, then hand it to the machine.
  3. No sensitive data without a rule.What goes into the tool is decided in advance, who may open it is decided in advance, and the team knows the line before they experiment with it.
  4. No output without a trail.Everything an agent produces is traceable: what the instructions were, what the inputs were, who reviewed it. Without that, it is just confident text.

Automation does not fix a bad system — it only multiplies its speed.
